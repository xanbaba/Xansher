# Xansher

A simple, lightweight IDE for .NET development built with WPF and following the MVVM pattern.

## Features

- **Syntax Highlighting:** Provides syntax highlighting for C# and other .NET languages to improve code readability.
- **Project and File Management:** Easily create, open, and manage .NET projects and files within the IDE.
- **Build and Run Integration:** Build and execute your projects directly from the IDE interface.
- **Modern UI:** Clean and responsive user interface built with WPF.
- **Error and Output Window:** View build errors and application output in dedicated panels.
- **Code Navigation:** Quickly search and navigate through your codebase.
- **MVVM Architecture:** The application is structured using the MVVM pattern for maintainability and testability.

## Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/yourusername/Xansher.git
   ```
2. **Open the solution in Visual Studio (2019 or later).**
3. **Restore NuGet packages.**
4. **Build and run the project.**

## Usage

- Launch the application.
- Create or open a .NET project.
- Edit code files with syntax highlighting.
- Build and run your project directly from the IDE.
